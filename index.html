Things I've built.

01 · Computer vision

Color-Controlled Snake Game

Classic Snake, but you steer it by moving a blue object in front of your webcam instead of pressing keys. OpenCV captures the webcam feed, NumPy isolates the blue pixels to track the object's position, and Pygame handles the game logic and display.

  • Real-time video processing
  • Color-based object tracking
  • Keyboard-free controls
  • Python
  • OpenCV
  • NumPy
  • Pygame

02 · Embedded systems Team project

Smart Mobility Tank

An autonomous navigation vehicle that avoids obstacles on its own. Built on an ESP32 microcontroller with ultrasonic and IR sensors and servo motors, programmed in Arduino C/C++.

My role: researched the sensor-based navigation approach and prepared the project documentation and report.

  • ESP32
  • Arduino C/C++
  • Ultrasonic & IR sensors
  • Servo motors
